# Infinite Brutality Hanging Gardens Story Pilot II

Date: 2026-06-11

## Project

A second concrete Hanging Gardens district state now exists alongside the first pilot, and it is integrated instead of remaining only as source-packet scaffolding.

This pass proves the environmental-writing system can support contrast inside the same world family without breaking tone.

## What The Second Pilot Adds

- one contrasting hidden run-story state
- one shrine-rim district role
- 12 concrete nook packets
- witness-law motifs, silent bell residue, and sealed-route hope
- a bounded Claude packet pass integrated back into the canonical Infinite Brutality data file

## Chosen Story Pressure

This pilot is clerical, memorial, and infrastructural rather than domestic.

Core state:

- Chapel Custodians under collapse pressure
- Toll-Remnant Scribe administrative residue
- belltower collapse and route severance
- ritual substitution over doctrinal purity
- bridge-bell witness taboo
- sealed cistern reopening hope

The result is a district that reads through handprints, folded names, wrapped bell tongues, substitute offerings, and bureaucratic hope.

## Why It Matters

The first pilot proved absent-people domestic life.

The second pilot proves the system can also handle:

- failed warning infrastructure
- civic and devotional legitimacy friction
- memorial rule systems
- witness-count logic as social glue
- hope preserved as queue, ledger, and prepared route instead of prophecy

That makes Hanging Gardens feel like a settlement with multiple survivor cultures, not one generic tragic voice.

## Reusable Pattern

A durable environmental-writing workflow for this project is now:

1. choose a district role
2. choose one hidden run-story state
3. bind it to packet families and repeated motifs
4. build a narrow source packet
5. run a bounded external writing pass
6. integrate the returned fragments into the canonical pilot JSON
7. preserve the source, prompt, raw output, and source refs in Thunder
