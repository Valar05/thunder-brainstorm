# Blend Archaeology Program — 2026-09-14

## Mission

Treat Drew's historical Blender files as a design corpus.

For each specimen, preserve source identity, inspect the surviving model/animation evidence, reconcile it with Drew's memory, extract mechanic/animation/style grammar, and keep only the smallest lessons that improve future work.

This uses the existing Thunder Brainstorm pattern:

```text
source observation
-> compact abstraction
-> lineage / pattern
-> future design leverage
```

It does not create a second giant memory system.

## Repo split

**Pose Lab V2** is the binary/source and visual-inspection side:

- canonical `.blend` archive;
- SHA/provenance manifest;
- Blender structural inventory;
- contact sheets / renders / motion evidence;
- animation-specific diagnostics.

**Thunder Brainstorm** is the thinking side:

- compact source references;
- session learnings;
- style / motion / mechanic abstractions;
- cross-project lineage;
- promoted pattern cards only when repeated evidence earns them.

Story Brainstorm is not used for this corpus because its mission is specifically rights-verified pre-1930 written works and its boundaries exclude unrelated project payload.

## Per-specimen output budget

Each finished blend should reduce to approximately:

```text
source identity + hash
3-7 verbs
1 style signature
<= 5 lessons
<= 4 lineage links
1 strongest future-use rule
```

Raw object lists and frame evidence stay in Pose Lab / generated evidence surfaces.

## Style is mandatory

Every specimen gets style analysis in addition to mechanics and animation.

Required style lenses:

- silhouette grammar;
- proportion grammar;
- shape language;
- surface/material grammar;
- detail economy;
- deformation style;
- camera dependence;
- era/tool fingerprint when source-supported;
- later recurring Drew signatures only after cross-specimen evidence exists.

## Historical production evidence

Production history is not trivia. Preserve whether motion was fully authored, mocap-derived, key-reduced, retimed, retargeted, procedural, or hybrid.

A particularly valuable test is when two opposite methods converge on the same causal grammar.

Current known example from Gravity Fist / Pose Lab:

- AxeKick and Headbutt: USER_MEMORY says fully authored.
- Most other Ares strikes: USER_MEMORY says mocap-derived with keys removed.
- Pose Lab later reduced those actions again to semantic read poses.

This creates a construction-vs-excavation comparison for animation and prose.
