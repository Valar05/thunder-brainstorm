# Fleshpunk Maze progression gallery

Thunder now owns a dedicated visual-archaeology route at `/gallery/fleshpunk-maze`. The gallery preserves six ordered stages from the rejected deterministic box diagram through the current pressure-valve line master and exact binary training plate.

Reusable rules:

- Keep visibly rejected work in sequence and label it `QUARANTINED`; deletion erases the causal lesson.
- Mirror external project images into Thunder with exact source and gallery SHA-256 values.
- A contact sheet is a selection overview, not a substitute for the full-resolution champion.
- Gallery progress and training acceptance are different state machines. The last plate remains `AWAITING_USER` until its exact pixel aggregate is accepted.
- A visual gallery needs a stable dedicated route, touch-sized stage navigation, full-resolution access, and an explicit before/after comparison—not a directory listing.
- Run the Thunder server durably in tmux and verify the exact route, manifest marker, and image bytes before handoff.
