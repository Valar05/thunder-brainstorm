# Last Convoy — Optional Vehicle Breadth

**Date:** 2026-09-14
**Status:** user-provenance design observation + source-compatible interpretation

## Observation

Drew identifies another source of Last Convoy's purity: the feature set is externalized into convoy vehicles.

The game can already be complete with a very small role vocabulary, roughly three meaningful vehicle identities. Adding another twelve or fifteen vehicles is therefore optional breadth rather than repair work required to make the core game whole.

This is compatible with the source structure: convoy pickups become follower vehicles and role-specific vehicles can contribute distinct combat behavior while preserving the same player-facing steering grammar and snake-style chain.

## Why this matters

A game can be complete before its content catalog is complete.

```text
CORE GRAMMAR
steer + constant motion + timed lead cannon + convoy geometry + enemies

MINIMAL ROLE SET
just enough vehicles to prove that convoy composition matters

OPTIONAL CATALOG
additional vehicles that create new combinations without being required for basic completeness
```

This separates **system completeness** from **content abundance**.

Adding a new vehicle does not need to enlarge the control scheme or rewrite the game's central sentence. It can simply add another capability that the existing sentence knows how to carry.

## Design consequence

The healthy expansion path is:

```text
complete small game
-> expose a stable extension seam
-> add optional modules through that seam
-> stop whenever desired
```

The base artifact does not become retroactively incomplete merely because more modules are possible.

## Compact rule

> **Finish the grammar early; let the catalog remain open.**

> **A feature seam is healthy when stopping at three and continuing to eighteen are both legitimate outcomes.**
