# Decomposable Creative Capability Stack

**Date:** 2026-09-14
**Status:** active brainstorm / systems theory

## Observation

Drew's engine thesis extends beyond games.

The recurring pattern is not "make every medium personally." It is:

```text
artifact -> reusable capability -> lower cost for next artifact
```

Once game-making itself becomes decomposed into reusable capabilities, adjacent media begin to expose the same structure:

```text
story -> game logic / scene structure / dialogue / world state
image -> art direction / asset generation / layout / transformation
video -> sequencing / staging / timing / camera / audio / motion
speech -> voice / performance / narration
music -> composition / arrangement / synthesis / mix
```

The important claim is bounded: the path becomes technically intelligible and increasingly composable. It does not imply that one person must do every medium, that quality is automatic, or that distribution, licensing, compute, rights, audience, and craft disappear.

## Creative sovereignty principle

The deeper objective is to separate **the ability to create a medium** from **the industry that currently packages and controls the expensive production path for that medium**.

Games are the clearest first specimen because they already combine many media. A sufficiently capable game-making engine naturally accumulates powers useful to story, image, animation, video, voice, sound, and music.

This creates a capability stack:

```text
TEXT / STORY
-> SCENE / WORLD MODEL
-> IMAGE / ASSET
-> MOTION / ANIMATION
-> VOICE / SOUND / MUSIC
-> INTERACTION
-> GAME
-> VIDEO / RECORDING / PERFORMANCE OUTPUT
```

The arrows are not one-way. A story can generate game structure; a game can generate stories; a game runtime can stage video; animation systems can generate imagery; image systems can feed games and video; voice and music can move independently across all of them.

## Bad House connection

A Bad House makes creative capability contingent on recurring extraction, permission, gatekeeping, or institutional scale.

A capability commons does the opposite:

```text
learn once
-> preserve capability
-> reuse freely
-> lower the next cost
-> distribute authorship
```

The goal is therefore not merely cheaper content production. It is **decomposable authorship**: creative power survives outside the institution that historically bundled the labor, capital, permissions, and distribution needed to exercise it.

## Important restraint

Do not turn this into a totalizing promise.

The claim is not:

> Drew will personally master every medium.

The claim is:

> The dependency graph is becoming visible, reusable capabilities can cross medium boundaries, and open tooling can make those capabilities increasingly portable and communal.

That distinction matters. The path can exist without becoming an obligation.

## Compact doctrine

> **Do not confuse the industry that currently manufactures a medium with the underlying capabilities required to create that medium.**

And:

> **When capabilities become modular, reusable, and open, authorship can move across media without asking the old production house for permission each time.**
