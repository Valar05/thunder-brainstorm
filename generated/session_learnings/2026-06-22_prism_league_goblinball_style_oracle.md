# Prism League Goblinball Style Oracle

Date: 2026-06-22
Project: `/storage/emulated/0/Documents/GodotProjects/prism-league`

## Decision

The Goblinball style image is the source of truth for visual development, not a source of assets.

## Core Rule

Every output should read like a collaboration between an engineer and a goblin.

- Engineer: structure, function, calibration, reliability, readability.
- Goblin: decoration, personalization, commentary, poor decisions.

## Drift Checks

- Keep brass, crystal, wood, and dark iron visible.
- Keep goblin green as an accent, not the whole world.
- Keep the arena machine-like, not like a random battlefield or dungeon room.
- Keep effects readable on phone scale.
- Reject anything that could fit equally well in a generic fantasy, sci-fi, or battle-royale game.

## Reusable Rule

When a Goblinball asset or UI element is being reviewed, ask whether it looks engineered first and goblin-owned second. If either half is missing, it does not belong.
