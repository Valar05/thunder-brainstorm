# Signal Reclamation / Corrective Salience — 2026-09-14

## Trigger

A chain of observations from the blend archaeology and Lexen Vigil discussion converged on the same operator:

- retro technical limitation can become style rather than deficiency;
- weird morphology can remain memorable even when rendering is modest;
- stop-motion can preserve visible discontinuity and fabrication rather than smoothing them away;
- pain can carry corrective salience without being intrinsically good.

The useful generalization is not that unpleasantness is valuable by itself.

It is:

> **A negative or uncomfortable signal should not be removed before determining whether it carries information the system still needs.**

## Signal reclamation

Working sequence:

```text
SIGNAL
-> ATTENTION
-> MODEL UPDATE
-> CORRECTION
-> RECOMPOSITION
```

The design error is premature smoothing:

```text
uncanny -> polish away
weird -> normalize
pain -> anesthetize immediately
failure -> hide
technical limitation -> upgrade before asking what the limit contributes
```

Some of those removals are correct. Some destroy the very information that made the artifact or lesson legible.

## Stop motion bridge

Stop motion often keeps visible:

- stepped motion;
- fabricated bodies;
- material surfaces;
- small registration discontinuities;
- the contradiction between "this object is alive" and "this object is clearly an object."

It can therefore turn perceptual wrongness into an intentional aesthetic channel.

Working formulation:

```text
PERCEPTUAL ERROR + ARTISTIC CUSTODY = STYLE
```

This is not a claim that all stop motion sits inside the strict uncanny-valley hypothesis. It is a design observation that some perceptual discontinuities become beautiful when the medium owns them rather than apologizing for them.

## Weirdness as identity density

Rendering fidelity is only one route to memorability.

A strange relationship can carry more identity than a technically flawless familiar object.

Examples already found in the archaeology:

- Remhir: gargoyle wings are defensive / countering anatomy rather than decoration;
- Slime: soft pseudopods carry visible internal bone weapons;
- Lionheart: extreme silhouette hierarchy and semantic polygon allocation produce high visual impact at a low technical budget.

Working law:

```text
WEIRD RELATIONSHIP
-> prediction error
-> attention
-> memory
```

The key is not randomness. The strange feature must still be coherent enough to become a stable model in the viewer's head.

## Lexen Vigil and pain

The Lexen generalization is **corrective salience**, not "pain is good."

Pain is not intrinsically virtuous and is not a perfectly reliable error detector. It can be excessive, misleading, chronic, coercively imposed, or unrelated to useful correction.

The character-level mechanism is narrower:

> Pain can make consequence difficult to abstract away.

An intellectual error can remain elegant and untouched. A painful consequence may force attention onto the fact that something actually happened.

```text
ERROR
-> CONSEQUENCE
-> SALIENCE
-> ATTENTION
-> CORRECTION
```

Lexen's strength is therefore not pain-seeking. It is increasing willingness to let painful information cross the identity boundary without automatically converting it into self-protection.

```text
THIS HURTS
!=
THEREFORE I WAS RIGHT

THIS HURTS
!=
THEREFORE SOMEONE ELSE MUST PAY
```

The deeper skill is **correction surviving contact with identity**.

## Vigil as governor

Vigil keeps the mechanism from collapsing into cruelty.

The governing questions are:

- Who caused the consequence?
- Who carries it?
- Is it proportional?
- Is it bounded?
- Is meaningful choice or exit preserved?
- Can the interpretation itself be corrected?
- Is the signal reporting reality, or has power manufactured suffering and then renamed obedience as growth?

The doctrine is therefore:

```text
CONSEQUENCE MUST BE ALLOWED TO REMAIN LEGIBLE
```

not:

```text
PAIN IS GOOD
```

Pain may increase salience. Vigil decides whether that salience remains under humane custody.

## Candidate doctrines

### SIGNAL RECLAMATION

Before removing an uncomfortable signal, determine whether it carries information that the intended system still needs.

### CORRECTIVE SALIENCE

A consequence becomes useful when it reliably captures attention and improves the next model or action. Salience is valuable; suffering itself is not.

### CUSTODY OF CONSEQUENCE

A corrective signal is only defensible when agency, proportionality, ownership, exit, and correction remain visible.

### CONTROLLED UNCANNY

A perceptual discontinuity can become aesthetic material when it is intentionally bounded and coherent with the work's grammar.

## Cross-corpus relation

```text
retro limitation -> style
weirdness -> memorability
uncanniness -> aesthetic tension
pain -> corrective salience
failure -> diagnostic evidence
```

Common law:

> **Do not smooth away every prediction error.**

Some prediction errors are noise. Some are harm. Some are the information the system came to discover.

## Guardrail

Never infer that pain, trauma, coercion, illness, or suffering should be sought because they can carry information.

The useful design principle concerns preserving truthful feedback and consequence, not manufacturing harm.

## Compact form

```text
SIGNAL -> ATTENTION -> UPDATE -> CORRECTION -> RECOMPOSITION
```

The creator's job is not to eliminate every unpleasant signal.

The creator's job is to know which signals are noise, which are harm, and which are load-bearing truth.
