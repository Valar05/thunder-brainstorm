## Reusable Rule

A generated place should validate causality, not only geometry. Repairs need prior damage or stress; retrofits need old structure and visible adaptation; material mismatches need phase boundaries; abandoned routes need replacement, purpose, or intentional ruin; current player routes must match lifecycle state.
