## Purpose

Mine older Google Drive project artifacts into Thunder Brainstorm without copying the artifacts wholesale.

The goal is cross-referenceable source refs:

- Drive links remain attached to their original artifacts.
- Thunder Brainstorm records the source role, freshness, project mapping, and likely skill cluster.
- GitHub remains canonical for active software implementations.
- Drive remains historical/project memory unless a current archaeology report promotes a specific artifact.

## Cross-Reference Rule

Every Thunder Brainstorm Drive source ref should point to:

1. Original Drive artifact.
2. Live GitHub source if one exists.
3. Relevant Home Center skill cluster or archaeology report.
4. Any known duplicate/mirror artifacts.

This turns Drive from attic boxes into source-linked archaeological evidence. Less dusty goblin cave. More museum with knives.
