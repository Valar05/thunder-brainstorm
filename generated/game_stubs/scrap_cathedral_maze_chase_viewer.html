Candidate

scrap_cathedral_maze_chase_v1

Theme Pitch

Setting
A derelict iron cathedral whose maintenance drone (the player) must reclaim scattered charge rivets before security choir units hunt it down by resonance.
Collectibles
Charge rivets (small, required) and greed clusters (dense optional caches).
Reversal Pickup
Breaker overload node — briefly overwhelms choir units' resonance sensors, making them vulnerable.
Bonus Item
Salvage relic — appears on a timed route, grants a run-currency bonus if collected.
Pursuers
Four choir units, each a distinct patrol subroutine etched into rusted iron frames.
Why It Works
Industrial decay maps cleanly to tile damage, gate locks, alarm tiles, and hardware-module upgrades without borrowing any protected identity.

Core Loop

  1. Enter a seeded maze floor; read pursuer mutation icons before movement begins.
  2. Move on simultaneous ticks; collect all required charge rivets to unlock the exit.
  3. Avoid choir units; use breaker overload nodes to reverse threat briefly.
  4. Optionally detour into greed clusters for bonus score at increased risk.
  5. Collect salvage relic if the route cost is acceptable.
  6. Exit floor; choose one upgrade module from three offered.
  7. Repeat for five floors; escalating speed and modifier stacking increase pressure.

Movement Model

Style
Simultaneous tick-grid: player and all pursuers resolve movement each tick.
Rationale
Preserves arcade pressure and makes pursuer logic inspectable; turn-based would collapse the chase tension.
Input Buffering
Player queues one directional input; it executes at the next valid intersection tile.
Tick Rate Ms
150
Collision Rule
Occupying the same tile as a choir unit on the same tick counts as contact.
Wrap Tunnels
Optional per-floor; one horizontal wrap corridor may exist, announced in floor preview.

Maze Generation

Algorithm
Seeded recursive-backtracker with mandatory loop injection: after base generation, add random cross-links until at least two distinct loops encircle the center region.
Grid Size
21x21 tiles for prototype; expandable to 27x27 in later floors.
Determinism
All RNG sourced from a single 32-bit floor seed; same seed always produces identical maze, collectible placement, and pursuer spawns.

Placement Rules

  1. Required rivets distributed across all reachable regions via flood-fill check post-generation.
  2. Greed clusters placed in high-risk corridors near choir spawn zones.
  3. Breaker overload nodes placed at least 5 tiles from player start; max 4 per floor.
  4. Salvage relic spawns on a bonus lane tile with a timed despawn of 12 seconds.
  5. Gate doors placed only where an alternate route exists; Gate Key upgrade bypasses one per floor.

Scoring And Pressure

Required Rivet
10 points each.
Chain Bonus
Collecting 10 rivets consecutively without reversing direction multiplies next rivet value by 1.5x.
Reversal Chain
Eating 2 choir units in one window: 200pts; 3 units: 500pts; 4 units: 1200pts.
Greed Cluster
50 points per rivet; alarm_floor modifier activates on collection.
Salvage Relic
300 points; despawns after 12 seconds; route detour is always required.
Floor Debt
Leaving more than 30% of greed clusters uncollected reduces upgrade choice pool from 3 to 2 on next floor.
Escalation
Each floor increases base tick rate by 8ms and reduces reversal window by 1 second; floor 4+ adds one pursuer mutation.

Debug And Validation

  1. Debug overlay toggle (F1): renders each choir unit's current target tile as a colored crosshair matching unit color.
  2. Mode label: each unit displays a small text badge — CHASE, SCATTER, VULNERABLE, REARM — updated every tick.
  3. Flood-fill reachability check runs post-generation; any required rivet in an unreachable region triggers a reseed with seed+1.
  4. Loop count validator: confirms at least 2 distinct loops encircle the center 7x7 region before floor is accepted.
  5. Dead-end required-rivet check: flags any required rivet in a dead-end tile and relocates it to the nearest corridor junction.
  6. Seed replay: storing the floor seed and upgrade sequence allows exact floor reconstruction for bug reports.

Risks

  1. Simultaneous tick collision at high speeds may feel unfair; mitigate with a 1-tick grace window on first contact per respawn.
  2. Seeded maze generation may produce low-loop mazes on edge-case seeds; loop injection post-pass is mandatory, not optional.
  3. Pursuer mutations stacking on floor 4+ may create unreadable combined behaviors; cap active mutations at 2 total across all units.
  4. Greed cluster floor debt mechanic may feel punishing to new players; add a one-time tutorial floor with debt disabled.
  5. Browser tick-rate consistency varies; use a fixed accumulator loop, not requestAnimationFrame delta alone, to keep movement deterministic.

  5. scoring multiplier table
  6. floor escalation curve (tick rate delta, reversal window delta per floor)

Hardcoded In Engine

  1. BFS pathfinding for VECTOR and PINCER
  2. tick accumulator and input buffer
  3. flood-fill reachability validator
  4. collision and reversal state machine
Build Order
Maze generation and validator first, then four pursuers with debug overlay, then collectibles and reversal, then one floor modifier, then upgrade selection screen.
First Milestone
A single seeded floor with all four pursuers, 80 rivets, 4 breaker nodes, debug overlay active, and a win condition — playable in under 2 weeks solo.
