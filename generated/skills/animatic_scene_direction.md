# Animatic Scene Direction Skill Mirror

Installed skill: `.codex/skills/animatic-scene-direction/SKILL.md`

Use this Thunder mirror to find the workflow from corpus search. The skill directs animatics, motion visuals, and parallax 2D assets in 3D scenes through asset inventory, shot beats, depth stack, camera plan, implementation, visual acceptance, and durable Thunder capture.

Core reusable pattern: stage 2D assets as purposeful depth planes with anchors, camera beats, and visual acceptance evidence; preserve accepted or rejected scene-direction lessons as `generated/session_learnings` plus `generated/source_refs_manual` records.

July 2026 update: pacing and voice are part of direction. Conversational animatics should not hold overlong between beats except for named intentional pauses, and multi-speaker scenes should use distinct Cartesia voice profiles or documented equivalents rather than one narrator/main-character voice with pitch shifts.

Camera update: the skill now treats camera moves as named grammar. Locked camera is the default for dialogue/testimony; push-ins, pull-backs, pans, tilts, dollies, shake, and roll each need a beat reason and mobile-readable timing. Idle drift and unmotivated roll are critique failures.


July 2026 frame eligibility update: animatic stitching must compile audio/script beats into audience knowledge, allowed visual states, forbidden visual states, and an eligibility class before rendering. A visual noun match is not enough; a frame can show the right object while implying the wrong chronology, access, or consequence. Contact sheets are asset inventories, not timelines. Beats with no eligible image should reuse a narratively correct frame or mark `new_asset_required` rather than cutting to a dramatic but false later state.
