# Source Packet: Immune Cell Maze-Chase Roguelike

## Goal

Create a first playable game stub for a rights-safe arcade maze-chase roguelike with a fleshpunk-style immune-system theme. The player is a white blood cell. The enemies are infection agents. The required pellets are antibodies.

## Core Translation

- Player: white blood cell moving through damaged tissue channels.
- Required collectibles: antibodies that mark defended tissue sites.
- Reversal pickup: complement burst, briefly allowing the cell to consume infection agents.
- Pursuers: infection behaviors with stable, readable personalities.
- Bonus temptation: memory antigen, useful but teaches the infection about the player's body habits.
- Maze: capillary/tissue cross-section with membranes, loops, necrotic pockets, and lymph gates.

## Fleshpunk-Esque Rules

Use generalized principles only, not Fleshpunk names or prose. Body options should be concrete tactical identities. A good adaptation changes routes, costs, recognition, and later enemy behavior. Pure baseline discipline should be viable. Mutations/adaptations should not be simple keys; they should solve one pressure while creating another.

## Prototype Bias

Keep simultaneous tick-grid movement. Keep four infection agents. Keep deterministic seeds and debug overlays. Make antibody reachability validation mandatory.
