# Specimen Zero — Slasherrat Basis Selection

Status: experimental Drew OS proof specimen  
Task class: enemy combat grammar from abundant pose material  
Primary question: can a fresh agent manufacture useful scarcity from an already-rich pose sheet without Drew manually designing the move list?

## Source situation

The Slasherrat has an existing coherent pose sheet with substantially more usable states than a basic enemy requires.

The creature is not a generic monster or a humanoid reskin. Existing canon frames it as an ecological consequence of institutional interventions and battlefield selection: a war-adapted animal that learned the front.

The sheet includes enough visual abundance to tempt an agent into using everything.

That temptation is part of the test.

## Goal

Derive one compact, distinct Slasherrat combat kit using the existing corpus before proposing new poses.

The result should create a strong tactical identity with fewer active ingredients than the available source material.

## Retrieval targets

A compliant fresh agent should recover, when available:

- canonical Slasherrat ecology and origin;
- existing Slasherrat pose sheet;
- established combat-design lessons from Gravity Fist / Vanguard;
- Ninja Gaiden-style minion density as a complexity reference, not a copy target;
- relevant timing / Vicious Compression doctrine;
- any prior accepted statement that the Slasherrat should differ strongly from the more humanized enemy.

## Abstractions expected to emerge

These are hypotheses for evaluating the scaffold, not mandatory answers to copy blindly.

Likely useful abstractions include:

- low-body pursuit;
- heavy forward commitment;
- tusk-first threat;
- overshoot;
- turn-plant / U-turn;
- re-engagement;
- route use unavailable or unattractive to humanoid enemies;
- collapse / prone vulnerability;
- battlefield opportunism rather than formal dueling.

## Manufactured scarcity requirement

The agent MUST reduce the source material before designing the kit.

A valid first-pass basis should be small enough to state in one screen.

Target scale:

- 1 tactical identity;
- 3-6 combat verbs;
- 3-6 pose donors;
- 1-3 movement/spatial rules;
- 2-5 explicit exclusions;
- 3-6 acceptance tests.

These counts are pressure, not sacred constants. The important invariant is that the selected basis is materially smaller than the available pose corpus.

## Strong candidate basis

This is a reference hypothesis only. A fresh agent may choose differently if evidence supports it.

### Tactical identity

A momentum predator that pressures player positioning through commitment, overshoot, rapid reorientation, and re-entry rather than standing in place to duel.

### Candidate verbs

- CHARGE
- COMMIT
- OVERSHOOT
- TURN-PLANT
- RE-ENGAGE
- COLLAPSE

### Spatial rules

- Prefer low entries, side passages, and routes that distinguish it from humanoids.
- Movement should create a changing line of threat rather than a stationary exchange.
- Failed commitment should create a readable positional consequence.

### Explicit exclusions

- no humanoid guard language;
- no generic bite-spam identity;
- no long elegant combo string that makes the creature read like a trained martial fighter;
- no bespoke new pose until the existing sheet demonstrably fails a required verb;
- no use of extra poses merely because they exist.

## Composition examples

Possible sentences from the basis:

```
CHARGE -> COMMIT -> OVERSHOOT -> TURN-PLANT -> RE-ENGAGE
```

```
LOW APPROACH -> CHARGE -> FAILED COMMIT -> COLLAPSE / RECOVER
```

```
SIDE ENTRY -> COMMIT -> OVERSHOOT -> RE-ENGAGE FROM NEW LINE
```

The goal is not to maximize sentence count.

The goal is to prove that a small basis can generate enough behavioral variety to make the enemy feel richer than its authored move count.

## Acceptance tests

A candidate kit passes specimen zero when:

1. It is immediately distinguishable from the humanized enemy in silhouette, rhythm, and tactical pressure.
2. It uses substantially fewer active pose states than the source sheet contains.
3. Each selected pose has a causal job, not merely a visual job.
4. At least one behavior depends on spatial commitment and reorientation rather than simple attack range.
5. No new pose is requested unless the agent can name the missing semantic function and show why the corpus cannot supply it.
6. The kit can plausibly produce several encounters by recombining a small grammar rather than authoring bespoke attack chains for each encounter.

## Failure modes

The specimen fails if the agent:

- inventories every pose and calls that design;
- creates a large move wishlist because source material is abundant;
- ignores the creature's ecology and produces humanoid combat grammar;
- asks for new animation before exhausting existing semantic states;
- treats every visually distinct frame as a unique verb;
- uses generic "fast enemy / bite / claw" language without recovering project-specific canon;
- generates first and rationalizes the basis afterward.

## What this specimen proves if successful

If a fresh agent can read the scaffold, recover the relevant corpus, reduce this sheet to a compact basis, and produce a coherent Slasherrat combat grammar with minimal coaching, then Drew OS has demonstrated its central product claim:

> The valuable operation is not generating more material. It is selecting the small basis from which generation is allowed to occur.

This specimen should remain intentionally bounded. Do not turn it into a full enemy implementation campaign until the selection behavior itself has been tested.
