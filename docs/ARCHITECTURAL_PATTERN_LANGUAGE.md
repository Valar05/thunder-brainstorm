# Architectural Pattern Language

Version: 0.2
Status: Corpus Refactor

This corpus is now split into three layers: canonical assemblies, mutation grammars, and composition phrases. The earlier repeated per-game cards were mined into this structure instead of being discarded.

Use the corpus like this: `Assembly + Mutation + Phrase`.

## Canonical Assemblies

====================================

NAME
Gatehouse

BOX BREAKDOWN
2 shoulder masses, 1 lintel block, 1 throat cut, 1 rear cap.

PROPORTIONS
Opening width 1x. Shoulder width 1.5x. Depth 1.5x to 2.5x opening width.

ADJACENCY RULES
Attach to approach halls, courts, stairs, or any route that needs a hard threshold.

CONSTRUCTION ORDER
Set shoulders. Bridge lintel. Cut throat. Cap rear mass.

STRUCTURAL PURPOSE
A threshold that compresses approach and turns entry into a readable commitment.

====================================

NAME
Arch Span

BOX BREAKDOWN
2 piers, 1 curved or stepped cap, 1 bridge slab.

PROPORTIONS
Span width 2x to 4x the pier thickness. Cap height 1x to 1.5x.

ADJACENCY RULES
Bridge two rooms, cross a drop, or mark a major route crossing.

CONSTRUCTION ORDER
Place piers. Add cap. Cut the void under the span.

STRUCTURAL PURPOSE
A supported crossing that points the eye forward while keeping the passage exposed.

====================================

NAME
Barrel Vault

BOX BREAKDOWN
2 end walls, 1 long ceiling mass, 1 floor channel.

PROPORTIONS
Length 3x to 5x the width. Ceiling rises at the center line.

ADJACENCY RULES
Use as a connector between major rooms or as the main pressure tunnel.

CONSTRUCTION ORDER
Lay floor. Cap side walls. Shape roof arc. Tighten the ends.

STRUCTURAL PURPOSE
A continuous shell that builds momentum while holding lane discipline.

====================================

NAME
Cross Vault

BOX BREAKDOWN
4 corner supports, 1 central crossing mass, 4 short ribs.

PROPORTIONS
Crossing arms stay equal or near-equal. Center stays dominant.

ADJACENCY RULES
Use where two or more routes meet without losing identity.

CONSTRUCTION ORDER
Set supports. Add ribs. Carve the negative space between them.

STRUCTURAL PURPOSE
A meeting point that gives four branches a shared anchor.

====================================

NAME
Courtyard

BOX BREAKDOWN
4 perimeter walls, 1 open center, 2 to 4 edge anchors.

PROPORTIONS
Center occupies 40 to 60 percent of the footprint. Edges stay thick.

ADJACENCY RULES
Use as a hub, reset room, combat collector, or route compressor.

CONSTRUCTION ORDER
Lay perimeter. Cut center. Add edge anchors or cover.

STRUCTURAL PURPOSE
An open middle surrounded by a thick border that makes route choice obvious.

====================================

NAME
Stair Run

BOX BREAKDOWN
1 stair spine, 2 side guards, 1 top landing, 1 bottom landing.

PROPORTIONS
Treads stay shallow. Total rise is 1.5x to 2x the run.

ADJACENCY RULES
Attach to landings, balconies, gates, or shaft entries.

CONSTRUCTION ORDER
Place landings. Step the core. Flank the run.

STRUCTURAL PURPOSE
A readable vertical change that makes ascent or descent feel deliberate.

====================================

NAME
Landing

BOX BREAKDOWN
1 flat platform, 2 side stops, optional 1 back rail.

PROPORTIONS
Width stays modest. Depth only needs to change pace.

ADJACENCY RULES
Place between stairs, lifts, and any change in direction.

CONSTRUCTION ORDER
Set platform. Add edges that stop overshoot.

STRUCTURAL PURPOSE
A pause point that gives the player a read before the next move.

====================================

NAME
Switchback Stair

BOX BREAKDOWN
2 stair flights, 1 turning platform, 2 side guards.

PROPORTIONS
Each flight is short enough to turn without losing rhythm.

ADJACENCY RULES
Use when a direct stair would be too long or too exposed.

CONSTRUCTION ORDER
Place first flight. Add turn. Mirror second flight.

STRUCTURAL PURPOSE
A zigzag ascent that forces a re-read midway through vertical travel.

====================================

NAME
Balcony

BOX BREAKDOWN
1 thin platform, 1 supporting wall or beam, 1 front edge.

PROPORTIONS
Platform depth stays thin. Front edge is the main mass.

ADJACENCY RULES
Pair with courts, halls, or vertical overlooks.

CONSTRUCTION ORDER
Set support edge. Project slab. Leave the drop open.

STRUCTURAL PURPOSE
A thin perch that lets the player look across or down without losing the route.

====================================

NAME
Overlook

BOX BREAKDOWN
1 high perch, 1 lip, 1 back mass, optional 1 undercut.

PROPORTIONS
Height matters more than width. Lip must stay readable.

ADJACENCY RULES
Attach to courts, pits, and routes that need a commanding view.

CONSTRUCTION ORDER
Raise perch. Carve underside. Leave a clean front lip.

STRUCTURAL PURPOSE
A high reading point that anchors the room and promises a route down.

====================================

NAME
Window Bay

BOX BREAKDOWN
2 wall blocks, 1 opening, 1 recess or reveal pocket.

PROPORTIONS
Opening stays smaller than the wall mass around it.

ADJACENCY RULES
Use in thick walls that need visibility without losing mass.

CONSTRUCTION ORDER
Lay wall. Cut opening. Deepen recess if needed.

STRUCTURAL PURPOSE
A controlled view cut that turns blind mass into a tactical frame.

====================================

NAME
Bridge Span

BOX BREAKDOWN
2 endpoints, 1 span slab, optional 2 rail masses.

PROPORTIONS
Span length is 2x to 4x the support width. Rails stay slim.

ADJACENCY RULES
Use across voids, pits, water, or machine gaps.

CONSTRUCTION ORDER
Place endpoints. Add slab. Add rails or broken edges.

STRUCTURAL PURPOSE
A commitment crossing that announces its line from a distance.

====================================

NAME
Side Passage

BOX BREAKDOWN
1 main wall block, 1 narrow spur, 1 return wall.

PROPORTIONS
The spur feels secondary but still fully walkable.

ADJACENCY RULES
Use to bypass the main route, hide resources, or fold back on itself.

CONSTRUCTION ORDER
Punch side opening. Extend spur. Keep the main wall thick.

STRUCTURAL PURPOSE
A lateral deviation that rewards players who check edges.

====================================

NAME
Service Tunnel

BOX BREAKDOWN
2 end caps, 1 narrow channel, optional 1 service pocket.

PROPORTIONS
Low ceiling and narrow width should be obvious from the start.

ADJACENCY RULES
Use between larger rooms or behind public-facing geometry.

CONSTRUCTION ORDER
Set caps. Keep the run low. Pull the ceiling close to the floor.

STRUCTURAL PURPOSE
A compressed utility corridor that makes interruptions feel louder.

====================================

NAME
Shaft

BOX BREAKDOWN
2 side walls, 1 vertical void, 1 base or top stop.

PROPORTIONS
Height should dominate footprint by at least 3x.

ADJACENCY RULES
Use where a route needs strong vertical change or a falling threat.

CONSTRUCTION ORDER
Set walls. Cut void. Add any platform or lift mass.

STRUCTURAL PURPOSE
A tall empty center surrounded by thick walls that reads as purposeful architecture.

====================================

NAME
Lift Cage

BOX BREAKDOWN
1 moving cage, 2 rails or guides, 1 shaft frame.

PROPORTIONS
The cage stays smaller than the shaft so motion is obvious.

ADJACENCY RULES
Attach to shafts, landings, and timed vertical access routes.

CONSTRUCTION ORDER
Frame shaft. Hang guides. Insert cage volume.

STRUCTURAL PURPOSE
A controlled moving block that turns dead vertical space into a route beat.

====================================

NAME
Choke Point

BOX BREAKDOWN
2 heavy side masses, 1 thin pass-through, optional 1 blocker.

PROPORTIONS
The opening should feel noticeably smaller than the room on either side.

ADJACENCY RULES
Place between louder spaces, patrol routes, or combat pockets.

CONSTRUCTION ORDER
Lay heavy sides. Carve narrow center. Add blocker if needed.

STRUCTURAL PURPOSE
A narrow legible slice of space that forces commitment and collision.

====================================

NAME
Alcove

BOX BREAKDOWN
1 recess, 1 lip, 1 rear wall, optional 1 side brace.

PROPORTIONS
Depth stays shallow enough to read as a pause, not a new room.

ADJACENCY RULES
Works inside thick walls, at corners, or beside larger route beats.

CONSTRUCTION ORDER
Cut recess. Keep lip thick. Add rear stop if needed.

STRUCTURAL PURPOSE
A carved pocket that gives the wall a hidden function.

====================================

NAME
Pit / Drop Well

BOX BREAKDOWN
1 floor break, 1 surrounding lip, 1 lower depth or hazard void.

PROPORTIONS
The opening should matter without collapsing the room shape.

ADJACENCY RULES
Use where falling, landing, or deliberate risk should change the route.

CONSTRUCTION ORDER
Mark lip. Cut opening. Deepen the void below.

STRUCTURAL PURPOSE
A dark void with a clean rim that turns position into a resource.

====================================

NAME
Catwalk

BOX BREAKDOWN
1 narrow path, 2 end supports, optional 1 rail or brace.

PROPORTIONS
Width stays thin. Length should stretch the player across exposure.

ADJACENCY RULES
Use above pits, machinery, courts, or open combat wells.

CONSTRUCTION ORDER
Set anchors. Draw thin span. Leave the void obvious under it.

STRUCTURAL PURPOSE
A suspended strip of mass that makes movement feel committed.

## Mutation Grammars

Each game is a grammar that mutates the same canonical assemblies instead of redefining them.

====================================

DOOM

SCALE
Compact.

VERTICALITY
Low and abrupt.

EXPOSURE
Close and punitive.

ROUTE LOGIC
Direct threshold, fast re-entry, killbox on the far side.

BEST MUTATIONS
Gatehouse, Courtyard, Balcony, Catwalk, Choke Point.

====================================

DOOM II

SCALE
Larger pressure rooms with denser crossfire.

VERTICALITY
More overlap, but still anchored to combat readability.

EXPOSURE
Safety gets revoked after the first read.

ROUTE LOGIC
Loopback punishment and route denial after the commitment.

BEST MUTATIONS
Gatehouse, Cross Vault, Courtyard, Switchback Stair, Catwalk.

====================================

QUAKE

SCALE
Stone-heavy and vertically compressed.

VERTICALITY
High shock, deep drops, strong ledges.

EXPOSURE
Arcs and voids matter more than decoration.

ROUTE LOGIC
A room should feel carved out of one mass.

BEST MUTATIONS
Arch Span, Shaft, Overlook, Pit / Drop Well, Courtyard.

====================================

QUAKE II

SCALE
Industrial and modular.

VERTICALITY
Machines, catwalks, shafts, service lifts.

EXPOSURE
Pipes and frames create the boundary language.

ROUTE LOGIC
Cross-route machine spaces with readable service access.

BEST MUTATIONS
Service Tunnel, Lift Cage, Catwalk, Bridge Span, Choke Point.

====================================

HALF-LIFE

SCALE
Grounded facility scale.

VERTICALITY
Practical stairs, catwalks, and control rooms.

EXPOSURE
Service logic, not spectacle.

ROUTE LOGIC
Readable detours and believable interruptions.

BEST MUTATIONS
Hall, Service Tunnel, Stair Run, Window Bay, Landing.

====================================

HALO CE

SCALE
Broad, heroic, and vehicle-readable.

VERTICALITY
Layered but generous.

EXPOSURE
Cover islands inside open arenas.

ROUTE LOGIC
Multiple exits stay visible from the entry.

BEST MUTATIONS
Courtyard, Balcony, Bridge Span, Overlook, Gatehouse.

====================================

HALO 2

SCALE
Broader interlock with stronger route switching.

VERTICALITY
Foreground and background routes both matter.

EXPOSURE
Layered firing positions and controlled crossings.

ROUTE LOGIC
One route watches another instead of replacing it.

BEST MUTATIONS
Courtyard, Balcony, Cross Vault, Bridge Span, Switchback Stair.

====================================

MARATHON

SCALE
Compact ship logic with dense memory.

VERTICALITY
Functional, not theatrical.

EXPOSURE
Short views and repeated anchors.

ROUTE LOGIC
Players connect rooms as a system, not as isolated scenes.

BEST MUTATIONS
Service Tunnel, Side Passage, Hall, Landing, Shaft.

====================================

THIEF

SCALE
Shadow-friendly and sound-aware.

VERTICALITY
Quiet climbs, balconies, and hidden descents.

EXPOSURE
Broken sightlines and safe pauses.

ROUTE LOGIC
Patrol overlap is the real wall.

BEST MUTATIONS
Alcove, Window Bay, Balcony, Side Passage, Stair Run.

====================================

DISHONORED

SCALE
Roofline plus canal plus street layers.

VERTICALITY
Strong top, middle, and low plane choices.

EXPOSURE
The target and the route should both be visible.

ROUTE LOGIC
Traversal is authored by the player’s chosen plane.

BEST MUTATIONS
Balcony, Overlook, Bridge Span, Window Bay, Catwalk.

====================================

DARK SOULS

SCALE
Oppressive, ancient, and spatially memorable.

VERTICALITY
Shortcuts, return routes, and earned elevation.

EXPOSURE
Narrowness, weight, and distant landmarks.

ROUTE LOGIC
The room changes meaning after the player knows the return path.

BEST MUTATIONS
Gatehouse, Stair Run, Overlook, Shaft, Bridge Span.

====================================

BLOOD

SCALE
Cruel compression and ritual threat.

VERTICALITY
Aggressive thresholds and sudden drops.

EXPOSURE
Trap-heavy and ceremonial.

ROUTE LOGIC
The room feels like an instrument for punishment.

BEST MUTATIONS
Gatehouse, Choke Point, Courtyard, Pit / Drop Well, Alcove.

====================================

DUKE NUKEM 3D

SCALE
Playable public interiors with toybox logic.

VERTICALITY
Obvious stairs, balconies, and lifts.

EXPOSURE
Secret seams and readable utility space.

ROUTE LOGIC
Curiosity should always reveal a second path or joke pocket.

BEST MUTATIONS
Window Bay, Side Passage, Balcony, Lift Cage, Hall.

## Composition Phrases

These are sentence patterns for assembly sequencing. They tell the generator how architecture should progress, not just which nouns to place.

====================================

NAME
Compression -> Reveal

PURPOSE
Narrow the route before opening the room.

EMOTIONAL EFFECT
Tension, then relief.

GAMEPLAY EFFECT
Forces a read, then grants a clearer next move.

COMMON GAMES
Doom, Quake, Half-Life, Dark Souls.

WHY IT WORKS
Compression sharpens silhouette and makes the next space legible by contrast.

====================================

NAME
Hall -> Choke -> Arena

PURPOSE
Turn a neutral connector into a fight sentence.

EMOTIONAL EFFECT
Calm, squeeze, then impact.

GAMEPLAY EFFECT
The player commits through the choke and emerges into a controlled combat space.

COMMON GAMES
Doom, Doom II, Halo CE, Blood.

WHY IT WORKS
A hallway only matters when it changes the odds at the exit.

====================================

NAME
Courtyard -> Balcony Ring

PURPOSE
Wrap an open center with elevated edges.

EMOTIONAL EFFECT
Exposure with options.

GAMEPLAY EFFECT
Lets the player read the whole fight plane and choose a high or low route.

COMMON GAMES
Halo CE, Halo 2, Dishonored, Quake.

WHY IT WORKS
The ring gives the center a boundary and gives the edges tactical value.

====================================

NAME
Bridge -> Tower

PURPOSE
Use a crossing to point upward into a landmark.

EMOTIONAL EFFECT
Progress, then dominance.

GAMEPLAY EFFECT
Creates a traversal beat that resolves into a vertical destination.

COMMON GAMES
Quake, Halo 2, Dishonored, Dark Souls.

WHY IT WORKS
A bridge points the player forward; a tower makes the endpoint feel earned.

====================================

NAME
Tower -> Stair -> Overlook

PURPOSE
Climb, pause, then read from above.

EMOTIONAL EFFECT
Effort, release, command.

GAMEPLAY EFFECT
Builds ascent into a readable tactical payoff.

COMMON GAMES
Dark Souls, Quake, Dishonored, Halo 2.

WHY IT WORKS
The rhythm gives the player a physical climb and a spatial reward.

====================================

NAME
Gatehouse -> Killbox

PURPOSE
Convert entry control into immediate pressure.

EMOTIONAL EFFECT
Commitment and threat.

GAMEPLAY EFFECT
Once the player crosses, the room already has an angle on them.

COMMON GAMES
Doom, Doom II, Blood.

WHY IT WORKS
The threshold becomes the first weapon in the room.

====================================

NAME
Lift -> Landing -> Balcony

PURPOSE
Turn ascent into a new reading plane.

EMOTIONAL EFFECT
Anticipation, then lookout.

GAMEPLAY EFFECT
Creates a controlled rise and a place to reorient before continuing.

COMMON GAMES
Half-Life, Halo CE, Dishonored, Quake II.

WHY IT WORKS
The lift removes the route from view; the landing gives it back in a better framing.

====================================

NAME
Service Tunnel -> Secret Exit

PURPOSE
Hide the bypass inside utility logic.

EMOTIONAL EFFECT
Discovery and relief.

GAMEPLAY EFFECT
Gives the player a safer or sneakier route without changing the main map logic.

COMMON GAMES
Half-Life, Marathon, Duke Nukem 3D, Thief.

WHY IT WORKS
Utility space already justifies hidden movement, so the secret feels natural.

====================================

NAME
Window -> Balcony -> Drop

PURPOSE
Show a route, perch on it, then force a fall or commit.

EMOTIONAL EFFECT
Temptation, then risk.

GAMEPLAY EFFECT
Lets the player inspect a route before paying for it with position.

COMMON GAMES
Dishonored, Thief, Halo 2, Quake.

WHY IT WORKS
The window frames the option, the balcony holds it, the drop closes the sentence.

====================================

NAME
Vault -> Cross Vault -> Courtyard

PURPOSE
Use a roof system to resolve into a shared open center.

EMOTIONAL EFFECT
Order, then release.

GAMEPLAY EFFECT
Connects multiple approaches into a central tactical chamber.

COMMON GAMES
Half-Life, Halo CE, Quake II, Doom II.

WHY IT WORKS
The ceiling grammar organizes the approach and the courtyard resolves it.

====================================

NAME
Shaft -> Lift Cage -> Landing

PURPOSE
Make vertical travel feel mechanical and readable.

EMOTIONAL EFFECT
Risk, motion, then recovery.

GAMEPLAY EFFECT
Turns dead vertical space into a timed traversal beat with a landing payoff.

COMMON GAMES
Quake II, Half-Life, Halo CE, Doom II.

WHY IT WORKS
The shaft promises depth, the cage gives motion, the landing returns control.

====================================

NAME
Alcove -> Secret Cache

PURPOSE
Make a wall pocket feel purposeful.

EMOTIONAL EFFECT
Suspicion and reward.

GAMEPLAY EFFECT
Encourages the player to search edges for optional value.

COMMON GAMES
Thief, Duke Nukem 3D, Marathon, Blood.

WHY IT WORKS
A carved pocket always feels like it should hide something.

====================================

NAME
Catwalk -> Exposure -> Escape

PURPOSE
Turn a narrow bridge into a risk test and a release line.

EMOTIONAL EFFECT
Vulnerability, then relief.

GAMEPLAY EFFECT
Players cross under pressure and then escape into a safer volume.

COMMON GAMES
Quake II, Halo CE, Doom II, Half-Life.

WHY IT WORKS
The thin line is readable because exposure is the whole point of the beat.

====================================

NAME
Side Passage -> Loopback

PURPOSE
Fold the route back into a known space.

EMOTIONAL EFFECT
Discovery and control.

GAMEPLAY EFFECT
Turns an optional cut into a shortcut or alternate approach.

COMMON GAMES
Marathon, Thief, Dark Souls, Duke Nukem 3D.

WHY IT WORKS
A side passage is only fully legible when it changes future navigation.

====================================

NAME
Choke -> Switchback -> Overlook

PURPOSE
Make a hard stop lead into a higher reading point.

EMOTIONAL EFFECT
Pressure, then command.

GAMEPLAY EFFECT
The player clears or threads a bottleneck and then gains a spatial advantage.

COMMON GAMES
Doom II, Blood, Halo 2, Quake.

WHY IT WORKS
The choke makes the ascent feel earned and the overlook meaningful.

## Migration Note

The previous per-game matrix was the source material for this refactor. The raw source reading is preserved in git history and in the session note for this pass, so the corpus can be audited without keeping the old duplication in the main document.

If a future generator needs the older matrix shape, it should be regenerated from the canonical assemblies and mutation grammars rather than copied forward by hand.
