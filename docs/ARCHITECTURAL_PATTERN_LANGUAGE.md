# Architectural Pattern Language

Version: 0.1
Status: Corpus Seed

This is a first-pass structural corpus for procedural environment generation. It is intentionally about assemblies, proportions, adjacencies, and route control. It is not a history note, a style guide, or a critique of taste.

The document is organized by game because the same atomic forms behave differently under different route grammars. Each entry is kept at box level so the language can be reused by generators, blockouts, and human layout work.

## Doom


====================================

NAME
Gatehouse

PURPOSE
Doom favors hard transitions, quick re-entry, and layouts that turn aggression into route memory. This entry is used as a gatehouse assembly.

PLAN VIEW
#######
#  ## #
#######

SIDE VIEW
#####
#___#
#####

BOX BREAKDOWN
2 shoulder masses, 1 lintel block, 1 throat cut, 1 rear cap.

PROPORTIONS
Opening width 1x, shoulder width 1.5x, height 2.5x to 3x.

COMMON VARIATIONS
sealed gate, split gate, double gate, broken lintel

ADJACENCY RULES
Attach to halls, yards, and stairs; thicken the approach side.

GAMEPLAY PURPOSE
Use the assembly to force a push, then make the same space readable from a new angle. Stops flow long enough to force a read before the player commits.

SIGHTLINE PURPOSE
End long views with a hard mass or a doorway cut so the player reads the next threat fast. Frames the next space and hides the first threat behind the cut.

WHY IT LOOKS GOOD
Heavy slabs, hot interiors, and clear silhouette breaks keep the space readable under speed. A heavy outer frame around a narrow opening reads instantly as a threshold.

BUILD ORDER
Set shoulders, bridge the lintel, cut the throat, then cap the back mass.

PROPORTIONS

COMMON VARIATIONS

ADJACENCY RULES

BOX BREAKDOWN
1 moving cage, 2 rails or guides, 1 shaft frame.

PROPORTIONS
The cage stays smaller than the shaft so its motion is obvious.

COMMON VARIATIONS
open cage, enclosed cage, counterweight cage, broken cage

ADJACENCY RULES
Attach to shafts, landings, and rooms that need timed vertical access.

GAMEPLAY PURPOSE
Use the assembly to expose obvious traversal plus hidden backdoors and throwaway joke spaces. Converts a dead vertical gap into a controlled route beat.

SIGHTLINE PURPOSE
Readable practical space works best when it hides at least one optional route or secret pocket. The moving cage becomes a visible landmark inside the shaft.

WHY IT LOOKS GOOD
Clean utility geometry with a few deliberate interruptions keeps the level legible and playful. A compact moving block inside a larger frame is easy to parse and remember.

BUILD ORDER
Frame the shaft, hang the guides, then insert the cage volume.
